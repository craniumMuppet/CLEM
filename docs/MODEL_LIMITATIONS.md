# Model limitations

## Historical AMOC mean state

Coupled Low-complexity Earth Model v2.29.28 with the validated Repair R13 configuration underestimates the RAPID-era absolute AMOC strength in the SSP2-4.5 historical trajectory.

- CLEM 2004–2020 mean: approximately 14.17 Sv at 10° and 14.32 Sv at 5°.
- RAPID 26.5°N comparison used during review: 16.9 ± 1.2 Sv.

This bias is intentionally documented rather than post-hoc tuned after the held-out validation.

## Interpretation

CLEM is a reduced-complexity climate model. Passing the included conservation, sensitivity, AMOC, hosing, cross-resolution, and SSP2-4.5 tests does not make it a substitute for a comprehensive coupled Earth-system model or observational product.
