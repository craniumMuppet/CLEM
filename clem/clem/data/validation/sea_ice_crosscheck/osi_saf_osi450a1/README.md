# OSI SAF OSI-450-a1 v3.1 independent cross-check

This directory contains an independently processed concentration-derived
March/September area series from EUMETSAT OSI SAF OSI-450-a1 v3.1.

Required files:

- `N_03_fixed_mask_crosscheck.csv`
- `N_09_fixed_mask_crosscheck.csv`
- `METADATA.json`

The product is never used to tune EGCM. It is an untuned cross-check that tests
whether a calibration to NOAA/NSIDC G02202 generalizes to a separately processed
sea-ice concentration climate record.
